# بروشور دیجیتال و تعاملی کنسرت «موسیقی نو در ایران»
## Interactive Digital Concert Brochure: *New Music in Iran*
### آثار علیرضا مشایخی | Works by Alireza Mashayekhi

یک بروشور دیجیتال، تعاملی، تاریک و واکنش‌گرا (موبایل‌محور) برای کنسرت آثار علیرضا مشایخی در تالار وحدت تهران، پیاده‌سازی شده بر پایه متن رسمی بروشور (فایل DOCX) و دارایی‌های هویتی رویداد.

An interactive, dark-only, mobile-first digital brochure for the concert of pioneer composer Alireza Mashayekhi at Vahdat Hall, Tehran, built from the authoritative Word document brochure text and official brand assets.

---

## 🌟 ویژگی‌های برجسته | Key Features

1. **طراحی بر پایه اولویت موبایل (Mobile-First)**:
   - بهینه‌سازی دقیق برای عرض‌های متداول گوشی همراه (۳۲۰، ۳۶۰، ۳۷۵، ۳۹۰، ۴۰۲ و ۴۳۰ پیکسل).
   - کنترل فواصل و حاشیه‌های افقی و جلوگیری از سرریز محتوا.
   - ابعاد لمسی مناسب برای دکمه‌ها و پیوندها (حداقل ۴۴ پیکسل).

2. **طراحی بصری تماماً تاریک (Dark-Only)**:
   - تم تاریک دائمی متناسب با فضای تاریک سالن کنسرت در شب.
   - پالت رنگی استخراج شده مستقیماً از فایل `color.svg`:
     - رنگ تاکیدی قرمز-نارنجی: `#eb644c`
     - رنگ زمینه تیره قهوه‌ای-مشکی: `#261c0b`
     - رنگ متن عاجی/استخوانی: `#e6ded0`
   - پرهیز از فلاش سفید یا تغییر ناگهانی نور.

3. **دوزبانه کامل (فارسی / انگلیسی)**:
   - زبان پیش‌فرض: فارسی (`lang="fa"`, `dir="rtl"`).
   - زبان دوم: انگلیسی کامل (`lang="en"`, `dir="ltr"`).
   - تغییر جهت کامل المان‌ها و کنترل‌ها همراه با **حفظ موقعیت مطالعه کاربر** هنگام جابجایی میان زبان‌ها.

4. **وفاداری کامل به متن منبع بروشور (DOCX Source Fidelity)**:
   - یادداشت تحلیلی کامل «تداوم تفکر» به قلم دکتر هانی اشرفی (۷ پاراگراف بدون تلخیص).
   - رپرتوار کامل ۶ اثر با رعایت توالی دقیق اجرا، شماره‌های اپوس، سال تصنیف، سازبندی و نشان «نخستین اجرای جهانی» در آثار مشخص شده.
   - نشانگر «تنفس» (Intermission) در جایگاه دقیق مندرج در بروشور منبع.
   - شرح‌حال کامل هنرمندان: علیرضا مشایخی، امین غفاری، آرش امینی، ستاره بهشتی و فرزان فرنیا.
   - اسامی کامل تمامی نوازندگان در بخش‌های‌سازی آنسامبل کوبه‌ای کاروان، کوارتت زهی نماد و ارکستر زهی خلیج‌فارس.
   - عوامل اجرایی و سپاسگزاری‌ها.

5. **استفاده وفادارانه از دارایی‌های برند**:
   - فایل وکتور تایتل (`تایتل.svg`) به صورت کاملاً دست‌نخورده و بدون تغییر در هدر و بخش آغازین.
   - استفاده معنادار از فرم ویولن (`فرم ویالن.svg`) به عنوان بافت ساختاریافته در پس‌زمینه.
   - بارگذاری مستقیم ۴ وزن فونت اصیل «اَبَر» (`AbarMidFaNum-Medium`, `SemiBold`, `Bold`, `ExtraBold`).

6. **کارگاه آفرینش نگاره‌های تجسمی (AI Visual Art Studio)**:
   - قابلیت آفرینش نگاره‌های تجسمی معاصر با مدل `gemini-3-pro-image-preview`.
   - امکان انتخاب رزولوشن تصویر در سه اندازه: **1K** (۱۰۲۴ پیکسل)، **2K** (۲۰۴۸ پیکسل) و **4K** (۴۰۹۶ پیکسل).
   - انتخاب نسبت ابعاد (1:1، 16:9، 9:16، 4:3، 3:4).
   - مضامین آماده برگرفته از رپرتوار کنسرت و امکان دانلود تصویر.

7. **امکانات کاربردی تماشاگران**:
   - دانلود فایل رویداد تقویم (`.ics`) و ثبت در تقویم گوگل.
   - پیوند مستقیم مسیریابی به تالار وحدت.
   - تنظیم اندازه قلم متن مقاله برای خوانایی در تاریکی سالن.
   - دکمه شناور بازگشت به بالا.

## 📂 ساختار دارایی‌ها و پروژه | Project Assets

- `public/fonts/`: فونت‌های رسمی اَبَر (Medium, SemiBold, Bold, ExtraBold).
- `public/assets/`:
  - `color.svg`: مبنای استخراج توکن‌های رنگی.
  - `تایتل.svg` (`title.svg`): تایتل رسمی رویداد (بدون تغییر).
  - `فرم ویالن.svg` (`violin-form.svg`): فرم گرافیکی ویولن.
  - `پوستر.svg` (`poster.svg`): مرجع هویت بصری کنسرت.
- `src/data/brochureData.ts`: داده‌های متنی دوزبانه استخراج‌شده از فایل DOCX.
- `src/components/`: کامپوننت‌های ماژولار React.
- `server.ts`: سرور Express فول‌استک با اتصال به مدل `gemini-3-pro-image-preview`.

## 🚀 نحوه اجرا | Getting Started

### ۱. نصب وابستگی‌ها:
```bash
npm install
```

### ۲. اجرای محیط توسعه (Development):
```bash
npm run dev
```
سرور بر روی پورت ۳۰۰۰ اجرا می‌شود (`http://localhost:3000`).

### ۳. ساخت نسخه نهایی (Production Build):
```bash
npm run build
```

### ۴. اجرای نسخه نهایی:
```bash
npm start
```

## 🔍 گزارش شفافیت و راستی‌آزمایی | Editorial & Asset Transparency

- **فونت لاتین**: در مخزن دارایی‌ها فونت لاتین اختصاصی موجود نبود؛ بنابراین از سیستم سنز-سریف سازگار (`system-ui`, `-apple-system`, `Segoe UI`, `Roboto`) استفاده شده است.
- **یادداشت بازبینی عنوان ستاره بهشتی**: در متن بروشور منبع عبارتی به صورت «شاید به این عنوان چند سطری متن اضافه شود و شاید حذف شود.» قید شده است. این یادداشت در بخش هنرمندان به صورت شفاف با نشان بازبینی برای ویراستار نمایش داده شده است.
